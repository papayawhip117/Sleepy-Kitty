# Sleepy-Kitty
Idle desktop game, no progression just chill and for aesthetic de-stress purposes

## Run it

```bash
npm install
npm run dev     # open the link Vite prints
npm run build   # production build in dist/
```

Time of day follows your real clock and the season follows the calendar. Move the mouse to show the small controls (time, season). Click the bed, window sill, desk or rug to send the kitty there.
